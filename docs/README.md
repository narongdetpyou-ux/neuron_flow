# Documentation

Maintained documentation, notebook instructions, examples, issue forms and
displayed system messages use English. Business data remains UTF-8: changing
interface language does not translate customer descriptions or alter source bytes.
Frozen fixtures and archived release evidence retain their original content and
hashes. Historical paths in machine records describe the files at that run.
